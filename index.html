Diese Seite braucht JavaScript

Wenn du das hier liest, wurde die Datei in einer Vorschau geöffnet – zum Beispiel über einen iCloud-Link oder direkt in der Dateien-App. Solche Vorschauen führen kein JavaScript aus, deshalb bleibt die App leer.

Die Datei muss auf einem Webserver liegen und über eine https-Adresse in Safari oder Chrome geöffnet werden, etwa über GitHub Pages oder Netlify Drop. Danach über „Teilen → Zum Home-Bildschirm“ ablegen.
